# Project Architecture & Screenshots Directory

This directory is reserved for UI dashboards, SCADA monitoring screenshots, and architectural system diagrams for the **Smart Municipal District Cooling & Ice Thermal Energy Storage System**.

## Visual Assets & Dashboards:
1. **Central Cooling Plant SCADA Dashboard**: Displays centrifugal chillers, dual-mode glycol chillers, water temperatures, and COP efficiency metrics.
2. **Ice Thermal Energy Storage (ITES) Monitoring**: Real-time State of Charge (SOC %), ice level meters, glycol loop delta-T, and charge/discharge mode toggles.
3. **Municipal Hydraulic Cooling Network**: Geographical GIS map showing the underground district piping, municipal substations (ETS), differential pressures, and cooling load demand per zone.
4. **Time-of-Use Dispatch Optimizer**: Real-time cost comparison graph contrasting baseline power consumption against ITES peak-shaving dispatch.
