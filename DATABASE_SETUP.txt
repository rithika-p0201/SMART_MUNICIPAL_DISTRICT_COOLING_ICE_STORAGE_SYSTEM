SMART MUNICIPAL DISTRICT COOLING & ICE THERMAL ENERGY STORAGE (ITES) SYSTEM
DATABASE SETUP & CONFIGURATION GUIDE
========================================================================================

PROJECT OVERVIEW:
This enterprise system monitors and optimizes a centralized district cooling plant coupled
with an Ice Thermal Energy Storage (ITES) system. It enables load-shifting by freezing ice 
during off-peak nighttime electricity tariffs and melting it during on-peak daytime cooling 
demand hours to shave municipal electrical peak demand and reduce carbon emissions.

----------------------------------------------------------------------------------------
OPTION A: QUICK START WITH IN-MEMORY H2 DATABASE (ZERO SETUP REQUIRED)
----------------------------------------------------------------------------------------
By default, the application is pre-configured with an in-memory H2 database.
No external database installation or setup is needed to start running and testing immediately!

1. Start the application:
   - Command line:  ./mvnw spring-boot:run
   - VS Code / IDE: Run 'DemoApplication.java'

2. Access the H2 Web Console:
   - URL:            http://localhost:8080/h2-console
   - JDBC URL:       jdbc:h2:mem:district_cooling_db
   - Driver Class:   org.h2.Driver
   - User Name:      sa
   - Password:       (leave blank)

----------------------------------------------------------------------------------------
OPTION B: PRODUCTION / PERSISTENT MYSQL DATABASE SETUP
----------------------------------------------------------------------------------------
If you wish to use a local or remote MySQL Server, follow these steps:

STEP 1: Log in to your MySQL terminal or MySQL Workbench
   mysql -u root -p

STEP 2: Create the Database & User
   CREATE DATABASE IF NOT EXISTS district_cooling_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   
   -- Optional: Create a dedicated user
   CREATE USER IF NOT EXISTS 'cooling_admin'@'localhost' IDENTIFIED BY 'district_cooling_2026';
   GRANT ALL PRIVILEGES ON district_cooling_db.* TO 'cooling_admin'@'localhost';
   FLUSH PRIVILEGES;

STEP 3: Execute the Schema & Seed Scripts
   You can run the provided SQL scripts located in the 'database/' directory:
   mysql -u root -p district_cooling_db < database/district_cooling_db_setup.sql

STEP 4: Update 'src/main/resources/application.properties'
   Comment out the H2 settings and uncomment the MySQL section:

   spring.datasource.url=jdbc:mysql://localhost:3306/district_cooling_db?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true
   spring.datasource.driverClassName=com.mysql.cj.jdbc.Driver
   spring.datasource.username=root
   spring.datasource.password=your_mysql_password
   spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQLDialect

----------------------------------------------------------------------------------------
CORE DATABASE TABLES CREATED:
----------------------------------------------------------------------------------------
1. municipal_zones        - Municipal zones (Hospital, Tech Park, Civic Center, Residential)
2. cooling_substations    - Energy Transfer Stations (ETS) with heat exchanger metrics
3. chiller_units          - Central chillers (Centrifugal & Glycol chillers with COP ratings)
4. ice_storage_tanks      - Thermal storage tanks (TR-hr capacity, SOC %, charge/discharge mode)
5. tariff_rates           - Time-of-Use electricity tariffs (Off-Peak, Mid-Peak, On-Peak)
6. dispatch_strategies    - Automated chiller vs ice melt load-dispatch decisions & cost savings
7. sensor_readings        - Real-time IoT sensor telemetry (Temperatures, Flow rates, Pressures)
8. system_alerts          - Safety and operating alerts (Glycol leaks, low Delta-T syndrome)
9. district_cooling_bills - Municipal monthly billing and carbon emission offset accounting
